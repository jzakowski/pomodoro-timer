## 💡 Key Principles

### For Future Agents:

1. **Code ≠ Feature**
   - Backend logic without UI is NOT complete
   - Every feature MUST have visible, clickable UI elements

2. **Be Specific**
   - ❌ "Upload button"
   - ✅ "Upload button in header (right side, image icon + text)"

3. **Test Everything**
   - Complete ALL test steps in the issue
   - Create screenshots as evidence
   - Save to `tests/verification/feature_[N]/`

4. **No Files in Root**
   - Test scripts → `tests/scripts/`
   - Screenshots → `tests/screenshots/` or `tests/verification/`

5. **Follow Issue Order**
   - Check for `assigned:agent` label first
   - Then: high → medium → low priority
   - Within priority: simple → medium → complex
